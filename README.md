# VIVE pogo enclosure

Prototype enclosure for the VIVE pogo PCB.

## Files

- `cad/Vive-Shoe.FCStd`: authoritative editable FreeCAD assembly, including feature history and embedded controller/PCBA references. Open with FreeCAD 1.1 or later. Some imported reference geometry is a fixed solid rather than a sketch-based model.
- `exports/print/`: upright shell STEP and STL files, positioned with their lowest point at Z=0. Prefer STEP for OrcaSlicer. `PCBA-flat-no-pins.step` is only a printable fit mockup, with underside projections removed; it is not a fabrication model.
- `exports/assembly/`: shells and complete assembly in their original assembly coordinates.
- `references/pcb/`: September 24 PCB STEP snapshot used to build the enclosure. The PCB's electrical source and manufacturing releases belong in the separate `vive-pogo` repository.
- `docs/`: design notes and validation evidence.
- `scripts/export_shells.py`: regenerate shell STEP/STL files from the saved FreeCAD model.

## Editing and exporting

Edit the native document and save before regenerating exports. The export script reads the saved file; it does not rebuild the model from scratch. Historical one-off migration scripts are deliberately omitted because they depend on older versions and machine-specific paths.

The document uses FreeCAD's native Part-workbench constructive-solid-geometry workflow. This is intentional: the shoe is driven by shared lofts and boolean tools before branching into two printable solids. The editable source objects are preserved rather than collapsed into final imported shapes.

Expand the `VIVE shoe assembly` container to find six ordered groups: editing guide and parameters, reference geometry, master construction, front-shell construction, rear-shell construction, and export outputs. Start with the in-model `READ ME - editing guide`, then edit the `00 Dimensions - edit column B, then recompute` spreadsheet for dimension-driven values or expand a construction group to edit its sketches and primitive features directly. Cuts, fusions, and common operations are derived results; edit their named input tools to change the geometry. Disconnected historical construction branches are kept in Git history rather than in the active CAD document.

Each shell branch includes `Round exposed outer rim - 0.8 mm`. It rounds only the exterior upper edge; the inner controller-contact rim and the shell mating plane are unchanged. The front branch ends with `Cut 45-degree screw-head roofs`, using two editable sketches to turn the unsupported upper arcs of the horizontal head recesses into printable teardrop roofs. The rear branch includes `Bevel rear PCB ceiling edges - 1.0 mm`, an editable 45-degree chamfer that reduces the flat supported ceiling around the connector opening without changing the PCB bosses or seating faces.

Run `scripts/export_shells.py` using FreeCAD's Python environment, or execute it from FreeCAD's Python console with `exec(compile(open(path).read(), path, 'exec'), {'__file__': path, '__name__': '__main__'})`, where `path` is the absolute script path. It resolves repository paths automatically. It exports only the two shells; re-export the full assembly from FreeCAD when reference components change. The PCB mockup is a preserved snapshot, not regenerated by this script.

Commit native CAD and matching exports together. Keep the current files in these folders; use Git history and release tags for future revisions rather than duplicating entire version folders.

## Printing and assembly

The supplied print orientation is upright, with the shoe bottom on the bed. The geometry includes 45-degree roofs over the front shell's horizontal screw-head recesses and a 1 mm rear-pocket ceiling bevel to reduce abrupt overhangs, but the PCB boss and seating faces deliberately remain flat. Inspect supports in the slicer, especially those functional faces and the remaining screw-shank overhangs; protect the controller-facing fit surface from support scarring. These are prototype exports, not a validated production print profile.

With Bambu Support for PLA/PETG, use ordinary model filament for the support base and select the support material only for the support/raft interface. This keeps the flat functional faces well supported while avoiding unnecessary filament changes throughout the entire support tree. Check the sliced preview before printing because automatic support placement depends on the selected profile and threshold.

Hardware baseline: four McMaster 96817A840 M2 x 4 screws per shoe. Nominal pilot diameter is 1.6 mm. Verify screw engagement and head clearance in the physical assembly.

## Fit status

The September 25 released PCB copy checked against the enclosure matched its board, connector and resistor geometry. No solid shell or PCB-screw intersections were found. The released contact pads are 2 mm diameter at 3 mm pitch and match the opening.

The connector touches the rear shell nominally. The sampled insertion path has a minimum clearance of about 0.014 mm; this is not a continuous-path or manufacturing-tolerance guarantee. The fabrication stack reports 0.89 mm overall versus the STEP's 0.8 mm substrate. A printed PCB mockup fitted successfully according to the user; assembled hardware still needs a physical fit and charging test.

See `docs/design-notes.md` and `docs/validation/` for the original design checks. Those JSON files predate the September 25 release review.
